# Conecta Extensão — Protótipo

Protótipo demonstrativo em HTML, CSS e JavaScript, sem dependências.

## Como abrir

Abra `index.html` com duplo clique no explorador de arquivos ou execute no terminal Linux:

```bash
xdg-open index.html
```

Não é necessário instalar nada nem iniciar um servidor. As alterações feitas durante a demonstração são temporárias e voltam ao estado inicial ao recarregar a página.
